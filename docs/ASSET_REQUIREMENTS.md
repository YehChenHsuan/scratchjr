# ScratchJr AI 素材需求清冊

本文件是提供或替換圖片的唯一依據。請勿先依畫面猜尺寸；狀態圖必須使用相同 viewBox 與安全邊界。

## 已確認缺項

| ID | 畫面／用途 | 提供檔名 | 格式與尺寸 | 透明 | 備註 |
|---|---|---|---|---|---|
| PWA-001 | PWA 主圖示母檔 | `app-icon-master.svg` | SVG，`viewBox="0 0 1024 1024"` | 否 | 主體位於中央 80% 安全區；將衍生 192、512、maskable 512、Apple 180 |
| WEB-001 | 瀏覽器 favicon | 由 PWA-001 衍生 | ICO，16/32/48 px | 是 | 目前 `/favicon.ico` 為 404 |
| UI-ROTATE-001 | 直向裝置旋轉提示 | `RotateDevice.svg` | SVG，`viewBox="0 0 256 256"` | 是 | ScratchJr 風格，不使用文字 |

`assets/fonts/verdana.ttf` 與 `verdanab.ttf` 的缺檔不列為使用者素材；程式改用合法的系統字型備援。

## 角色與背景交付

| 類型 | 首選 | 可接受來源 | 尺寸／範圍 | 規則 |
|---|---|---|---|---|
| 角色 | SVG | 透明 PNG | SVG 自帶 viewBox；PNG 建議 1024×1024、2 MB 以下 | 單一角色、透明背景、四周至少 8% 留白 |
| 背景 | SVG 480×360 | PNG 1920×1440 | 固定 4:3 | 完整畫面、無透明需求、避免重要物件貼邊 |
| UI 圖示 | SVG | 透明 PNG @2x | 依下方 UI 稽核結果 | 圖形保留至少 10% 安全邊界 |

## UI 稽核結果

目前自動化已覆蓋首頁、編輯器與 AI 訓練頁：除 favicon 與 Verdana 字型外，未發現其他網路 404。仍需使用者指出「看起來遺失」的動畫或按鈕狀態；收到截圖後，在此新增一列，欄位固定為：畫面、CSS/DOM 位置、狀態、正式檔名、viewBox/像素尺寸、透明度、安全邊界、參考截圖。

## 驗收

- 檔名大小寫完全相符。
- SVG 不含外部字型、外部圖片或 Canva 編輯器連結。
- 替換前後在 1440×900、1280×800、1366×1024 檢查無裁切。
