# 角色與背景匯入指南

1. 依 `docs/ASSET_REQUIREMENTS.md` 準備檔案。
2. 將核准素材交付至專案外的待審資料夾；不要自行覆蓋正式素材。
3. 開發者檢查透明度、viewBox、尺寸、檔名與授權來源。
4. 正式素材加入 `editions/free/src/svglibrary/`。
5. 在 `editions/free/src/media.json` 新增角色或背景項目。
6. 提供繁中 `name`，可選擇提供 `nameKey` 供其他語言翻譯。
7. 在角色庫／背景庫及已儲存專案中完成回歸測試。

第一階段僅匯入固定內建素材；兒童自行選檔匯入另開規格，避免把未驗證檔案直接加入作品資料庫。
